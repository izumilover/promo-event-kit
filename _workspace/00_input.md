# 프로젝트 입력 정리

## 앱 설명

## 프로젝트 형태

둘 다 — 재사용 가능한 컴포넌트 패키지(다른 앱에서 import) + 데모/쇼케이스 페이지를 포함하는
Next.js 앱. 컴포넌트 export 전략(내부 전용 vs 별도 패키지로 분리)은 Phase 2 아키텍처 설계에서
Option A/B/C로 확정한다.

풀스택(자체 DB) — 기획전/이벤트 데이터를 이 프로젝트의 Prisma + PostgreSQL로 직접 관리.
